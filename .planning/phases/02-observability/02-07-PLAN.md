**Change B — stackService.updateImages + route: capture pull output and detect no-update case**

`docker compose pull` writes to stdout lines like "nginx Pulling" / "nginx Pulled" when images update, and "nginx Image is up to date" when nothing changes. Capture this stdout and return it to the client so the UI can show the right message.

In `docker-executor.ts`, change `composePull` to return the stdout string instead of void:
```typescript
async composePull(stackId: string): Promise<string> {
    const {stdout} = await this.composeExec(stackId, ["pull"]);
    return stdout;
}
```

In `stack-service.ts updateImages()`, capture the pull output and detect whether all images were already up to date:
```typescript
async updateImages(id: string): Promise<{noUpdates: boolean}> {
    // ... existing transition to UPDATING ...
    let pullOutput = "";
    try {
        pullOutput = await this.docker.composePull(id);
        await this.docker.up(id);
    } catch (err: any) {
        // ... existing error handling ...
    }
    // ... existing transition to RUNNING ...
    await this.repo.clearConfigChanged(id);

    // "up to date" appears in stdout when no new layers were pulled
    // docker compose pull prints "Image is up to date" or "Already exists" for unchanged images
    const noUpdates = pullOutput.toLowerCase().includes("up to date") ||
        (pullOutput.trim().length === 0);
    return {noUpdates};
}
```
