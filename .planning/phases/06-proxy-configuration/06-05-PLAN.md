<objective>
Give the proxy feature a face: a Proxy tab on the stack detail page where a user
assigns, sees and removes domains with live certificate status, a Settings > Proxy card
that owns the ACME email, dashboard visibility and the deploy action, and a StackActions
bar that refuses destructive actions on the managed proxy stack instead of offering them.

Purpose: PRXY-01 and PRXY-04 are both phrased as things the user does "via the stack
detail page", and PRXY-03 as something "configurable in Settings" — none of them are
satisfied by a server that works and a UI that does not exist.

Output: `proxy-api.ts`, a `CertStatusBadge`, the `ProxyTab`, the `ProxySettingsCard`,
protected-action disabling in `StackActions`, and a Playwright spec covering the flows.
</objective>

<design_contract>
`06-UI-SPEC.md` is a contract, not a suggestion. The parts that bind every task here:

- **Two type weights only.** shadcn's `Label`/`FormLabel` ship a medium (500) default;
  every `Label` and `FormLabel` in this phase's new components overrides it to
  `font-semibold` so only 400 and 600 appear. No third weight value anywhere in the new
  files.
- **Spacing tokens:** `space-y-4` inside `CardContent`, `space-y-6` between cards,
  `gap-2` for compact controls, `ml-10` for a switch's disclosed sub-fields (reuse that
  exact indent, do not invent another).
- **Colour roles:** `var(--primary)` default `Button` for the primary submit only;
  `var(--destructive)` for remove, cert-failed and the D-11 deploy alert; the project's
  existing amber utility classes
  `bg-yellow-100 text-yellow-800 border-yellow-200 dark:bg-yellow-900 dark:text-yellow-200 dark:border-yellow-800`
  for the cert-pending badge and the D-13 host-port warning; `text-green-600` for the
  issued state. No new colour tokens.
- **Copywriting contract:** every user-visible string in the UI-SPEC's Copywriting
  Contract table is used verbatim. Do not improve the wording.
- **Focal point:** the domain `Table` (or its empty-state substitute) is the tab's
  primary anchor and renders above the assign form, not below it.
- **Checker FLAG to close:** the icon-only remove button carries an `aria-label`.
- No `shadcn init` and no new registry entries — every primitive this plan needs is
  already present in `client/src/components/ui/` (verified: `alert-dialog.tsx`,
  `tooltip.tsx`, `table.tsx`, `switch.tsx`, `form.tsx`, `skeleton.tsx`, `badge.tsx`,
  `alert.tsx`, `scroll-area.tsx` all exist).
</design_contract>

  <behavior>
    `CertStatusBadge({status, message})`:
    - `"issued"` renders the text "Secured" in the green success styling.
    - `"pending"` renders "Cert pending" in the amber warning styling.
    - `"failed"` renders "Cert failed" with the destructive Badge variant, and when `message` is present exposes it in a bounded scrollable monospace block.
    - An unknown or absent status renders the pending badge — the database default is `"pending"`, so "not reported yet" and "pending" are the same state by design.

    `ProxyTab({stackId, services})`:
    - While the initial fetch is in flight renders `Skeleton` placeholders inside a Card, never bare text and never an empty region.
    - When the fetched state reports the proxy stack is not deployed, renders the "Proxy stack not deployed" empty state with the "Go to Settings" button and renders no assign form.
    - When the proxy stack is deployed and there are no configs, renders the "No domains configured" empty state ABOVE the assign form.
    - When configs exist, renders one `Table` row per distinct `serviceName` with cells for domains, service, internal port, TLS, certificate status and actions; two domains for one service appear in one cell, not two rows.
    - Domain cells truncate with a native `title` attribute carrying the full value.
    - The certificate status shown for a row prefers a live `useProxyStatus` entry over the fetched row's stored `certStatus`.
    - The remove action opens an `AlertDialog` with the contract's copy; confirming calls `removeDomain` inside a `toast.promise` and reloads the list; cancelling calls nothing.
    - The remove trigger is an icon-only button carrying an `aria-label` naming the domain.
    - Submitting the assign form with an invalid domain shows a `FormMessage` and calls no API function.
    - A successful assign reloads the list; a rejected assign surfaces the thrown error's message through the toast's error branch.
    - When the selected service already publishes host ports, an amber non-blocking Alert renders reading "This service already publishes port {port} directly to the host. Enabling the proxy will not remove that binding — both will remain active." (D-13).
  </behavior>
