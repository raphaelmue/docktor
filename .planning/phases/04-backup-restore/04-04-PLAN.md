**1. Create `server/src/routes/backups.ts`:**

Import pattern matching existing routes:
```typescript
import type {FastifyPluginAsyncZod} from "fastify-type-provider-zod"
import {z} from "zod"
import {backupSettingsSchema, backupDefaultsSchema, stackBackupConfigSchema, restoreSnapshotSchema} from "@docktor/shared"
```

All routes must use `requireAuth` preHandler (import from `../lib/auth.js`).

Define route parameter schemas:
```typescript
const stackParamsSchema = z.object({id: z.string()})
const backupParamsSchema = z.object({id: z.string()})
```

The plugin registers these routes:

**Backup operations:**

`POST /api/stacks/:id/backup` — Trigger manual backup.
- Schema: `{params: stackParamsSchema}`
- Handler: calls `backupService.initiateBackup(params.id, "MANUAL")`, then `void backupService.runBackup(backup.id)` (fire-and-forget). Returns `reply.status(202).send({backupId: backup.id})`.

`POST /api/stacks/:id/restore` — Trigger restore from snapshot.
- Schema: `{params: stackParamsSchema, body: restoreSnapshotSchema}`
- Handler: calls `backupService.runRestore(params.id, body.snapshotId)`. Returns `reply.status(202).send({backupId: backup.id})`.

`GET /api/stacks/:id/backups` — List backup history for a stack.
- Schema: `{params: stackParamsSchema}`
- Handler: calls `backupRepository.findByStackId(params.id)`. Returns backups mapped through `backupRepository.toDto()`.

`GET /api/stacks/:id/snapshots` — List restic snapshots for a stack.
- Schema: `{params: stackParamsSchema}`
- Handler: first check stack status — if BACKING_UP or RESTORING, return `reply.status(409).send({error: "Backup in progress, try again shortly"})`. Otherwise calls `backupService.getSnapshots(params.id)`.

`GET /api/stacks/:id/volume-warnings` — Get absolute-path volume warnings.
- Schema: `{params: stackParamsSchema}`
- Handler: calls `backupService.getVolumeWarnings(params.id)`. Returns `{warnings: string[]}`.

**Single backup operations:**

`GET /api/backups/:id` — Get a single backup record.
- Schema: `{params: backupParamsSchema}`
- Handler: calls `backupRepository.findByIdOrThrow(params.id)`. Returns `backupRepository.toDto(backup)`.

`GET /api/backups/:id/stream` — SSE stream for backup progress.
- Schema: `{params: backupParamsSchema}`
- Handler: Follow the SSE pattern from `routes/events.ts`:
  ```
  reply.raw.writeHead(200, {
      "Content-Type": "text/event-stream",
      "Cache-Control": "no-cache",
      "Connection": "keep-alive",
      "X-Accel-Buffering": "no",
  })
  reply.raw.write(": connected\n\n")
  ```
  Load backup. If status is not IN_PROGRESS: stream stored logLines one by one, then send `{done: true, status}` and end. If IN_PROGRESS: get broadcaster via `getBackupBroadcaster(backup.id)`. If no broadcaster, end. Otherwise subscribe to `"line"` events and write `data: ${JSON.stringify({line})}\n\n`. Subscribe to `"done"` event and end. Wire `request.raw.on("close", ...)` to unsubscribe and resolve.
  IMPORTANT: `reply.hijack()` must be called before writing to `reply.raw` to prevent Fastify from trying to send a response.

**Per-stack backup config:**

`GET /api/stacks/:id/backup-config` — Get per-stack backup config.
- Schema: `{params: stackParamsSchema}`
- Handler: loads stack from stackRepository, reads stack.backupSchedule, stack.backupRetention (parse JSON), stack.backupPreHook, stack.backupPostHook. Gets global defaults. Returns `{useGlobalSchedule: !stack.backupSchedule, schedule: stack.backupSchedule, useGlobalRetention: !stack.backupRetention, retention: parsedRetention, preHook: stack.backupPreHook, postHook: stack.backupPostHook, globalSchedule, globalRetention}`.

`PUT /api/stacks/:id/backup-config` — Save per-stack backup config.
- Schema: `{params: stackParamsSchema, body: stackBackupConfigSchema}`
- Handler: updates Stack fields: `backupSchedule` (null if useGlobalSchedule), `backupRetention` (JSON.stringify or null if useGlobalRetention), `backupPreHook`, `backupPostHook`. Validate cron expression with `node-cron` validate() if schedule provided. Update backupScheduler: call `backupScheduler.upsert(stackId, schedule)` or `backupScheduler.remove(stackId)` accordingly. Returns 200.

**Settings routes (backup repository config):**

`GET /api/settings/backup` — Get backup repository settings.
- Handler: reads all `backup.*` settings keys. Returns object with repoType, repoPath, etc. Password returns `{hasPassword: boolean}` (never the actual value, same pattern as SMTP).

`PUT /api/settings/backup` — Save backup repository settings.
- Schema: `{body: backupSettingsSchema}`
- Handler: upserts all `backup.*` settings. Encrypts `password`, `sftpKey`, `s3SecretKey` using `encrypt()` from `lib/crypto.js`. Stores with `encrypted: true` flag on the Setting record via `prisma.setting.upsert({where: {key}, create: {key, value, encrypted: true}, update: {value, encrypted: true}})`.

`GET /api/settings/backup-defaults` — Get global default schedule + retention.
- Handler: reads `backup.defaultSchedule` and `backup.defaultRetention` settings.

`PUT /api/settings/backup-defaults` — Save global defaults.
- Schema: `{body: backupDefaultsSchema}`
- Handler: upserts `backup.defaultSchedule` and `backup.defaultRetention` (JSON.stringify the retention object).

`GET /api/settings/backup/status` — Check restic binary availability.
- Handler: calls `resticExecutor.checkVersion()`. Returns `{available: boolean, version?: string}`.

Export the plugin as default:
```typescript

```
