Class `BackupService`:
- Constructor takes `(resticExecutor: ResticExecutor, backupRepo: BackupRepository, stackRepo: BackupStackRepo, settings: BackupSettingsService, filesystem: BackupFilesystem, notificationService: NotificationService)`

- `async getBackupRepoConfig(): Promise<BackupRepoConfig | null>` — reads all `backup.*` settings via `this.settings.getSetting()`. If `repoType` is null, returns null. Decrypts `password`, `sftpKey`, `s3SecretKey` via `decrypt()`. Returns a `BackupRepoConfig` object.

- `async initiateBackup(stackId: string, trigger: "MANUAL" | "SCHEDULED"): Promise<{id: string}>` — loads stack via `stackRepo.findByIdOrThrow()`, calls `assertTransition(stack.status, "BACKUP")`, creates Backup record with `{stackId, trigger, status: "IN_PROGRESS", startedAt: new Date(), resticSnapshotId: ""}`, transitions stack to BACKING_UP via `stackRepo.transitionStatus()`. Returns `{id: backup.id}`.

- `async runBackup(backupId: string): Promise<void>` — the main orchestration method. Creates an EventEmitter, stores in `backupBroadcasters` map. Wraps everything in try/finally to clean up the emitter.
  1. Load the Backup record and the Stack record
  2. Get repo config (getBackupRepoConfig), fail if null
  3. Get retention policy: parse `stack.backupRetention` JSON or fall back to global default (`backup.defaultRetention` setting)
  4. Run pre-hook if configured (stack.backupPreHook) via `runHook()`
  5. Call `resticExecutor.run()` with `buildBackupArgs(stack.hostPath, stack.id)` and `buildEnv(repoConfig)`. Pass `onLine` callback that: (a) appends to accumulated lines array, (b) emits on the EventEmitter
  6. If exit code is 10, auto-init the repo (`resticExecutor.run({args: resticExecutor.buildInitArgs(), env, onLine})`) then retry the backup
  7. If exit code is non-zero (and not 10, or init retry also failed), throw with stderr
  8. Run `restic forget` with retention policy args
  9. Run post-hook if configured (stack.backupPostHook) via `runHook()`
  10. Update Backup record: status COMPLETED, completedAt, logLines, resticSnapshotId (parsed from JSON output if available)
  11. Restore stack to previousStatus via transitionStatus
  12. In catch block: update Backup to FAILED with errorMessage, transition stack to ERROR, call `notificationService.notify({type: "backup_failure", stackId, subject: "Backup failed: <stackName>", message: "<details including trigger type and repo type>"})`
  13. In finally: emit "done" on emitter, delete from backupBroadcasters

- `async runRestore(stackId: string, snapshotId: string): Promise<{id: string}>` — similar flow:
  1. Load stack, assertTransition(stack.status, "RESTORE")
  2. Create Backup record with trigger RESTORE, status IN_PROGRESS
  3. Transition stack to RESTORING
  4. Create EventEmitter, store in backupBroadcasters
  5. In background (void): try { stop stack (docker compose down), run resticExecutor.run with buildRestoreArgs(snapshotId), redeploy stack (docker compose up -d), update Backup to COMPLETED, restore stack to previousStatus } catch { update Backup to FAILED, transition stack to ERROR, notify backup_failure } finally { emit done, cleanup emitter }
  6. Return {id: backup.id}

- `async runHook(command: string, stackPath: string): Promise<{stdout: string; exitCode: number}>` — spawns `/bin/sh -c <command>` with cwd=stackPath. Collects stdout/stderr. Returns {stdout, exitCode}. Does not throw on non-zero (logged only).

- `detectAbsolutePathVolumes(composeContent: string, stackPath: string): string[]` — parses YAML, iterates over `doc.services[*].volumes`, for each volume: if short syntax (`host:container`), extract host part; if long syntax (`{source, type: "bind"}`), extract source. If `source` is absolute and does not start with `stackPath`, add `"${serviceName}: ${source}"` to warnings array. Return warnings.

- `async getSnapshots(stackId: string): Promise<ResticSnapshot[]>` — gets repo config, calls `resticExecutor.snapshots(config, stackId)`.

- `async getVolumeWarnings(stackId: string): Promise<string[]>` — reads compose content via filesystem, gets stack path, calls detectAbsolutePathVolumes.

- `async recoverInProgressBackups(): Promise<void>` — calls `backupRepo.findInProgress()`, for each: update status to FAILED with errorMessage "Server restarted during backup", restore stack previousStatus.

Class `BackupScheduler`:
- `private tasks = new Map<string, cron.ScheduledTask>()`
- Constructor: `(service: BackupSchedulerService, stackRepo: BackupSchedulerStackRepo, settings: BackupSchedulerSettings)`

- `upsert(stackId: string, cronExpr: string): void` — validate with `cron.validate(cronExpr)`. If invalid, log error and return. Stop existing task for stackId if any. Create new task via `cron.schedule(cronExpr, () => { void this.runScheduledBackup(stackId) })`. Store in map.

- `remove(stackId: string): void` — get task from map, call `.stop()`, delete from map. No-op if not found.

- `stop(): void` — iterate all tasks, call `.stop()` on each, clear the map.

- `async loadAll(): Promise<void>` — call `stackRepo.findAll()` (this should be a lightweight query). Get global default schedule via `settings.getSetting("backup.defaultSchedule")`. For each stack: use `stack.backupSchedule ?? globalDefault`. If schedule exists and is valid, call `upsert(stack.id, schedule)`. Log how many tasks were registered.

- `private async runScheduledBackup(stackId: string): Promise<void>` — try { call `service.initiateBackup(stackId, "SCHEDULED")`, then `void service.runBackup(backup.id)` } catch (err) { log error, do not throw (cron should not crash) }

Lazy production singleton pattern (same as disk-checker.ts):
```typescript
let _scheduler: BackupScheduler | null = null

async function createProductionScheduler(): Promise<BackupScheduler> {
    const {backupService, settingsService} = await import("../application/index.js")
    const {stackRepository} = await import("../repositories/stack-repository.js")

    return new BackupScheduler(
        backupService,
        {findAll: () => stackRepository.findAll()},
        settingsService,
    )
}

export const backupScheduler = {
    start: async () => {
        _scheduler = await createProductionScheduler()
        await _scheduler.loadAll()
    },
    stop: () => _scheduler?.stop(),
    upsert: (stackId: string, cronExpr: string) => _scheduler?.upsert(stackId, cronExpr),
    remove: (stackId: string) => _scheduler?.remove(stackId),
}
```
