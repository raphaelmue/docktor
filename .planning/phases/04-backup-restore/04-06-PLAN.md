**1. Create `client/src/routes/app/stacks/backups/[backupId].tsx`:**

Page component `BackupDetailPage` (export default).

Route params: `{id: string; backupId: string}` from `useParams`.

State:
- Load backup record via `getBackup(backupId)` on mount
- Use `useBackupStream(backupId, backup?.status === "IN_PROGRESS")` for live streaming
- `scrollRef` for auto-scroll to bottom

Renders:
```
Page:
  PageHeader:
    Breadcrumbs: Stacks > [stack name (from backup.stackId)] > Backups > [short ID]
    PageTitle: "Backup #{backup.resticSnapshotId.slice(0, 8) || backupId.slice(0, 8)}" or "Restore #{...}" based on trigger type
  PageContent:
    Card (metadata):
      Row with gap-4: BackupStatusBadge | trigger Badge (muted) | "Started: {date}" | "Duration: {formatted}" | "Size: {formatted}"
    Card "Output":
      CardHeader: "Output"
      CardContent:
        ScrollArea className="h-96" ref={scrollRef}:
          <div className="p-4 font-mono text-xs whitespace-pre-wrap" aria-live={streaming ? "polite" : "off"}>
            {lines from SSE hook OR backup.logLines}
          </div>
      If FAILED: Alert variant destructive at bottom:
        If trigger === "RESTORE": "Restore failed: {errorMessage}. The stack is in ERROR state. You can retry from the Backups tab."
        Else: "Backup failed: {errorMessage}"
```

Auto-scroll: use `useEffect` on `lines.length` to scroll to bottom of ScrollArea while streaming.

When backup is loaded and status is not IN_PROGRESS, display `backup.logLines` directly (no SSE). When status IS IN_PROGRESS, use the hook's lines.

Display logic:
- Title: if `backup.trigger === "RESTORE"` use "Restore #", else "Backup #"
- Duration: show "In progress..." if no completedAt, else format `completedAt - startedAt`
