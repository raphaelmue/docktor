    DockerodeClient:

    - getLogStream() calls container.logs with stdout:true, stderr:true, follow:true, timestamps:true, tail from arg (default 100)
    - inspectContainer(id) calls docker.getContainer(id).inspect()
    - listContainers(all) calls docker.listContainers({all})

    - publish(event) → all active subscribers receive the event
    - subscribe() returns an unsubscribe function that stops delivery
    - Multiple subscribers receive the same event independently

    - `inspectContainer(containerId)`: return `this.docker.getContainer(containerId).inspect()`
    - `listContainers(all = true)`: return `this.docker.listContainers({all})`
    - `getLogStream(containerId, tail = 100)`: return `this.docker.getContainer(containerId).logs({ stdout: true, stderr: true, follow: true, tail, timestamps: true })`
    - Export singleton: `export const dockerodeClient = new DockerodeClient()`

      - `subscribe(handler)`: `this.on("event", handler); return () => this.off("event", handler)`
    - Export singleton: `export const stateEventBroadcaster = new StateBroadcaster()`
    - Set `stateEventBroadcaster.setMaxListeners(100)` to suppress Node.js warnings with many SSE clients
