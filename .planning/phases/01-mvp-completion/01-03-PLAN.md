  <files>server/src/jobs/state-poller.ts</files>
  <behavior>
    - handleEvent() skips events where Actor.Attributes["com.docker.compose.project"] is absent
    - handleEvent() skips update when stack.status is in TRANSITIONAL_STATES = Set(["DEPLOYING","UPDATING","BACKING_UP","RESTORING","MIGRATING"])
    - handleEvent() calls dockerodeClient.inspectContainer(event.Actor.ID) and updates the matching Service row's containerState + healthStatus
    - handleEvent() derives the stack-level status from all its services' states after the update, writes it to Stack.status
    - handleEvent() calls stateEventBroadcaster.publish() with the resulting ContainerStateEvent
    - reconcile() calls dockerodeClient.listContainers(true), matches each container by compose labels, updates all matched Service rows in bulk; skips stacks in TRANSITIONAL_STATES
    - startEventStream() reconnects after 2000ms if the stream ends without an abort signal
    - stop() aborts the stream via AbortController.abort()
  </behavior>
  <action>
    Create server/src/jobs/state-poller.ts:

    ```typescript
    import cron from "node-cron"
    import {dockerodeClient} from "../infrastructure/dockerode-client.js"
    import {stateEventBroadcaster} from "../lib/state-broadcaster.js"
    import {prisma} from "../lib/db.js"
    import type {StackStatus} from "../generated/prisma/enums.js"

    const TRANSITIONAL_STATES = new Set<StackStatus>([
        "DEPLOYING", "UPDATING", "BACKING_UP", "RESTORING", "MIGRATING",
    ])
    ```

    Key implementation notes:
    - Stack lookup: query `prisma.stack.findUnique({where:{id:stackId}, include:{services:true}})`
    - Service update: `prisma.service.update({where:{id:service.id}, data:{containerId:event.Actor.ID, containerState:info.State.Status, healthStatus:info.State.Health?.Status ?? null}})`
    - Stack status derivation after update: use this priority rule:
      - If ANY service is "restarting" or "dead" → ERROR
      - If ALL running services are "healthy" (and at least one has healthCheck) → HEALTHY
      - If ANY service is "unhealthy" → UNHEALTHY
      - If ALL services are "running" (or no health check) → RUNNING
      - If ALL services are "exited" → STOPPED
      - Otherwise → RUNNING (default for mixed states)
    - Update stack status: `prisma.stack.update({where:{id:stackId}, data:{status:derivedStatus}})`
    - Then publish: `stateEventBroadcaster.publish({type:"container_state", stackId, serviceName, containerState, healthStatus, stackStatus:derivedStatus})`

    Reconciliation (reconcile() method):
    - `const containers = await dockerodeClient.listContainers(true)`
    - Group by `com.docker.compose.project` label
    - For each unique stackId: load stack from DB, skip if TRANSITIONAL, bulk-update services
    - Use `prisma.$transaction([...])` for bulk updates

    Constructor should accept optional `dockerodeClient` and `prisma` overrides for testability:
    ```typescript
    constructor(
        private readonly docker = dockerodeClient,
        private readonly db = prisma,
        private readonly broadcaster = stateEventBroadcaster,
    ) {}
    ```

    Export singleton: `export const statePoller = new StatePoller()`

    Anti-patterns to avoid:
    - DO NOT catch all errors silently — log them with `console.error` so they surface in dev
    - DO NOT call `process.exit()` on stream error — reconnect instead
    - MUST include `stream.on("end", () => ...)` with 2000ms setTimeout reconnect (Pitfall 4 from RESEARCH.md)

