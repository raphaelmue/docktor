## Spacing Scale

Declared values (multiples of 4 only). Applied via Tailwind utility classes:

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | gap-1 / p-1 | Icon gaps, badge internal padding |
| sm | 8px | gap-2 / p-2 | Inline element spacing, compact rows |
| md | 16px | gap-4 / p-4 | Card internal field spacing (space-y-4) |
| lg | 24px | gap-6 / p-6 | Page content padding (PageContent uses p-6) |
| xl | 32px | gap-8 / mt-8 | Section breaks between cards |
| 2xl | 48px | gap-12 | Major section breaks (not used in settings) |
| 3xl | 64px | gap-16 | Page-level spacing (not used in this phase) |

Exceptions: none. All spacing in this phase uses values from the standard set above.

Source: Existing settings.tsx uses `space-y-4` inside CardContent, `p-6` inside PageContent, `gap-2` for button groups — codebase inspection.

## Typography

All sizes and weights match the established pattern from dashboard.tsx, settings.tsx, and [id].tsx. No new sizes or weights are introduced.

| Role | Size | Tailwind | Weight | Tailwind | Line Height | Usage |
|------|------|----------|--------|----------|-------------|-------|
| Label / body | 14px | text-sm | 400 | font-normal | 1.5 | Form field labels, table cell text, toggle descriptions, notification log rows |
| Heading | 24px | text-2xl | 600 | font-semibold | 1.2 | PageTitle ("Settings") — unchanged from existing page |
| Card title | 16px | text-base | 600 | font-semibold | 1.25 | CardTitle inside Card components (shadcn CardTitle default) |
| Muted / caption | 14px | text-sm | 400 | font-normal | 1.5 | `text-muted-foreground` — field descriptions, timestamps in notification log |
| Badge / label | 12px | text-xs | 400 | font-normal | 1 | Badge components in notification log Email column and Type column |

Rule: Maximum 5 sizes declared (12, 14, 16, 24 — in practice 4 distinct sizes since 14px appears in two roles). Exactly 2 weights: 400 (font-normal) and 600 (font-semibold). Toggle labels and tab triggers use font-normal. CardTitle and PageTitle use font-semibold. Do not introduce new sizes or weights.

## Color

All colors are CSS variables declared in src/index.css using oklch. No hardcoded hex values in component code. Supports light and dark mode automatically.

| Role | CSS Variable | Light Mode | Dark Mode | Usage |
|------|-------------|------------|-----------|-------|
| Dominant (60%) | --background | oklch(1 0 0) = white | oklch(0.145 0 0) = near-black | Page background, PageContent area |
| Secondary (30%) | --card / --sidebar | oklch(1 0 0) / oklch(0.985 0 0) | oklch(0.205 0 0) | Cards, sidebar, tab content panels |
| Accent (10%) | --primary | oklch(0.205 0 0) | oklch(0.922 0 0) | Primary action buttons only |
| Muted surfaces | --muted | oklch(0.97 0 0) | oklch(0.269 0 0) | TabsList background, disabled states, skeleton loaders |
| Destructive | --destructive | oklch(0.577 0.245 27.325) = red | oklch(0.704 0.191 22.216) | SMTP validation errors, inline field error messages |

Source: src/index.css CSS variable declarations — codebase inspection.

**Primary visual anchor:** The SMTP card is the primary visual anchor — it is the largest and topmost element on the Notifications tab and contains the only two accent-colored CTAs on the tab ("Save SMTP Settings" and "Send Test Email").

**Accent reserved for:**
- The single primary "Save" button on each card's CardFooter
- The "Send Test Email" button on the SMTP card
- Active TabsTrigger indicator (managed by shadcn Tabs component internally)

**Accent NOT used for:**
- Toggle switches (use shadcn Switch default styling — --primary background when checked)
- Table rows, notification log entries, or status indicators
- Secondary/ghost action buttons

**Semantic colors for notification log rows:**

Use Tailwind semantic color classes consistent with existing badge pattern in [id].tsx:

| Notification type | Row/badge color | Class pattern |
|-------------------|-----------------|---------------|
| stack_error | Red tint | `bg-red-100 text-red-800 dark:bg-red-900 dark:text-red-200` |
| stack_unhealthy | Yellow tint | `bg-yellow-100 text-yellow-800 dark:bg-yellow-900 dark:text-yellow-200` |
| disk_warning | Orange tint | `bg-orange-100 text-orange-800 dark:bg-orange-900 dark:text-orange-200` |


Note: `h-12` (48px) is applied to the Switch for WCAG 2.5.5 touch target compliance (minimum 44px). This is a component-level height utility, not a spacing scale value. Toggle labels use `font-normal` (weight 400).

Toggles save immediately on change (no Save button). Show `toast.success("Notification settings saved")` on success.

## Interaction States

### SMTP Form

| State | Behavior |
|-------|----------|
| Loading | Skeleton loaders for all 6 fields (same height as Input, h-9) |
| Idle | Fields populated from API; Save and Test Email buttons enabled |
| Saving | "Saving..." label on Save button; both buttons disabled |
| Save success | `toast.success("SMTP settings saved")` |
| Save error (validation) | Inline `<p className="text-sm text-destructive">` under each invalid field |
| Save error (server) | `toast.error("Failed to save SMTP settings")` |
| Test send — pending | "Sending..." label on Test Email button; button disabled |
| Test send — success | `toast.success("Test email sent successfully")` |
| Test send — failure | `toast.error("Test email failed: " + error message from server)` |

### Notification Triggers

| State | Behavior |
|-------|----------|
| Loading | Skeleton loaders (h-4 for label, h-6 for switch) |
| Toggle change | Immediate API call; switch shows new value optimistically |
| Toggle save success | `toast.success("Notification settings saved")` |
| Toggle save failure | Revert switch to previous value; `toast.error("Failed to update notification settings")` |

### Notification Log

| State | Behavior |
|-------|----------|
| Loading | 3 skeleton rows, same height as table rows (h-10) |
| Empty | Empty state (see Copywriting Contract below) |
| Populated | Table rows, newest first, last 100 records |
| emailSent = true | Show "Sent" badge (variant="secondary") in Email column |
| emailSent = false | Show "UI only" badge (variant="outline") in Email column |
